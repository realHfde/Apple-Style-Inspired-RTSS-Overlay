<a id="get-started"></a>
### 🧭 Set up (about 5 minutes)

1. Install **MSI Afterburner with RTSS** and the **Inter font**. For Volt only, also **HWiNFO**.
2. Download the pack for your screen and copy the files from one theme folder into RTSS's `Overlays` folder.
3. In RTSS, load the `.ovl` in the Overlay Editor. Play!

**[📖 The full guide, step by step with pictures](docs/overlay-setup.md)** · [🧰 Optional extras](docs/overlay-extras.md) (hotkey, two GPUs, moving an overlay)

## 🖥️ Monitors & Widgets

RTSS overlays only show inside a game. Monitors & Widgets sits on the **desktop** instead, on any screen: a clock, your photo or video, what's playing, your apps, CPU, GPU, memory, FPS, network and drives. It is made for **Rainmeter**.
